# Unit 10 - SQL refresher
- Lookup tables lies 'zones' turn location IDs into readable names.
- A join combines rows from related tables using a key.
- 'INNER JOIN' keeps only matching rows from both sides.
- A fact table can join the same dimesion tables twice, once as pickup zone and once as dropoff zone.
- Data-quanlity checks use 'IS NULL' and 'NOT IN'.
- 'GROUP BY' agrregates rows by one or more dimesions.
- 'ORDER BY' sorts results by metric or dimension.

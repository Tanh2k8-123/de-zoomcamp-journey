# Module 5 Unit 10 - Core Concepts: Commands

- The `bruin validate` command checks that pipeline and asset definitions are well formed.
- The `bruin lineage` command displays dependency relationships between assets.
- The `bruin run` command executes the selected portion of the work.
- The `bruin query` command inspects results already stored in the database.
- Validation does not prove that every business rule or external connection will succeed at runtime.
- Inspect the affected scope before using upstream, downstream, or full refresh options.
- Available runtime flags depend on the CLI version actually installed.
- Output after a run still needs comparison against the expected source totals.

# Module 5 Unit 4 - Using Bruin MCP with AI Agents

- MCP exposes Bruin capabilities to a compatible AI client as an interface, not a storage engine.
- The MCP configuration format differs from one AI client to another.
- AI-generated assets still require review of their SQL, dependencies, connections, and execution scope.
- Generating a pipeline with an AI agent does not establish that its results are correct.
- An agent can explain existing lineage read-only, without changing or running anything.
- Small edits, inspected rendered SQL, and validation come before running an expensive pipeline.

# Module 5 Unit 4 — Using Bruin MCP with AI Agents

Status: Prepared study notes; not yet practiced in this learning repo.

## Core ideas

- MCP exposes Bruin capabilities to a compatible AI client; it is an interface, not a separate storage engine.
- AI-generated assets still need review of SQL, dependencies, connections, and execution scope.
- Prefer small changes, inspect rendered SQL, and validate before running an expensive pipeline.

## Practice plan

1. Read the course MCP setup for your client; configuration formats vary by application.
2. If choosing to connect later, first ask the agent to explain the existing lineage without changing or running anything.

## Understanding check

Why does generating a pipeline with AI not establish that its results are correct?

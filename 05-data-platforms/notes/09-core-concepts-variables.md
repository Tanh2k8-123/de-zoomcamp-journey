# Module 5 Unit 9 — Core Concepts: Variables

## Core ideas

- Runtime variables let the same pipeline process different dates or parameters without editing code.
- Distinguish built-in interval values from custom parameters. Inspect rendered SQL and CLI help for the installed release.
- For time intervals, make inclusive/exclusive boundaries explicit and align filters with replacement behavior.
- The supplied synthetic starter rebuilds small tables and intentionally has no interval filtering; extend it only after verifying boundary semantics.

## Practice plan

1. Study the date filters in the course NYC taxi example.
2. Write down the exact timestamp range meant by January before adding date variables to an asset.

## Understanding check

What happens if interval deletion covers January but the SELECT also inserts February?

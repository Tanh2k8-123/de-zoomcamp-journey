# Module 5 Unit 5 - Deploying to Bruin Cloud

- Managed execution moves scheduling and monitoring off the developer machine while pipelines stay code-driven.
- Deployment involves a repository, runtime connections, environments, and permissions.
- Connection settings are configured in the hosted environment instead of being committed to the repository.
- Cloud availability, limits, and pricing must be checked before choosing it for the final project.
- The intended path runs local development, then Git, then managed execution.
- This unit is reference-only, so it informs the final project choice rather than adding required setup.

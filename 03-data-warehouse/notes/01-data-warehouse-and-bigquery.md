# Module 3 Unit 1 — Data Warehouse and BigQuery

- OLTP systems support transactions; OLAP systems support analytics.
- A data warehouse stores analytical data from many sources for reporting.
- BigQuery is a serverless data warehouse.
- BigQuery separates storage and compute.
- BigQuery on-demand pricing is mainly based on bytes scanned.
- Public datasets can be queried directly in BigQuery.
- Warehouse design is about reducing scanned data and query cost.

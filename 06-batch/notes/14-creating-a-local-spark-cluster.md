# Module 6 Unit 14 — Creating a Local Spark Cluster

Status: Prepared study notes; not yet practiced in this learning repo.

## Core ideas

- A standalone master coordinates workers; workers host executors for submitted applications.
- spark-submit packages runtime configuration outside notebook state.
- Ensure worker-accessible inputs and matching runtime versions before moving from local mode.

## Practice plan

1. Read ../setup/README.md and the course standalone setup.

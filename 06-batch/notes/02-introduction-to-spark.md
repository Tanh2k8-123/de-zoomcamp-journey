# Module 6 Unit 2 — Introduction to Spark

## Core ideas

- Spark is a distributed processing engine; PySpark exposes its APIs to Python.
- Spark can run locally for learning and on clusters for larger workloads.
- DataFrames and Spark SQL express transformations that Spark plans and executes; it is not necessary to collect all rows into Python.

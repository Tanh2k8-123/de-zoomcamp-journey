# Module 4 Unit 1 - Analytics Engineering Basics

- Analytics engineering bridges data engineering and data analytics.
- It brings software practices into warehouse transformations: version control, tests, docs, modular SQL.
- dbt is mainly the transformation layer in ELT.
- Dimensional modeling uses fact tables for events/metrics and dimension tables for context.
- Star schema puts a fact table in the center and dimension tables around it.
- dbt projects usually have staging, intermediate, and marts layers.

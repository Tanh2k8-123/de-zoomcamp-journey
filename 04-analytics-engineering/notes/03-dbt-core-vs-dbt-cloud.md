# Module 4 Unit 3 - dbt Core vs dbt Cloud

- dbt Core: open-source CLI, you control setup and orchestration.
- dbt Cloud: SaaS IDE, scheduling, hosted docs, enviroment management, team features.
- Both are compatible; concepts transfer between them.
- dbt Fusion is the new rewrite engine but does not yet support DuckDB.
- For this course without GCP, we use DuckDB + dbt Core local.

# Module 2 Unit 2 — What is Kestra?

- Kestra is an open-source workflow orchestration platform.
- Workflows are declared as YAML flows.
- A flow contains ordered tasks.
- Each run of a flow is an execution.
- Kestra provides UI visibility: logs, states, inputs, outputs, retries, and executions.
- Kestra uses plugins to interact with Python, Docker, databases, HTTP APIs, and cloud services.

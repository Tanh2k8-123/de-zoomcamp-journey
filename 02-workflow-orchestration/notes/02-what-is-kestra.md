# Module 2 Unit 2 - What is Kestra?

- Kestra is an open-source workflow orchestrator.
- Workflows are declared ad YAML flows.
- A flow contains tasks.
- Each run of a flow is an execution.
- Kestra provides UI visibility: logs, states, retries, executions, and inputs.
- Kestra uses plugins to interact with Python, Docker, databases, APIs, and cloud services.

# Module 2 - What is Workflow Orchestration?
- An orchestrator coordinates multiple automated tasks.
- In data engineering, tasks usually extract, transform, load, validate, and publish data.
- Orchestration gives visibility: schedules, retries, alerts, logs, and backfills.
- Kestra represents workflows as declarative YAML flows.
- A flow contains tasks; each task has an id, type, and task-specific configuration.

# Module 2 Unit 1 — What is Workflow Orchestration?

- A workflow orchestrator coordinates many automated tasks.
- In data engineering, tasks can extract, transform, load, validate, and publish data.
- Orchestration adds visibility: schedules, logs, retries, alerts, and execution history.
- Kestra represents workflows as declarative YAML flows.
- A flow contains tasks; each task has an id, type, and task-specific configuration.

# Module 2 Unit 13 — Why AI for Workflows?

AI can help data engineers build workflows faster when it has the right context.

## Good AI use cases

- Generate YAML scaffolding for a new flow.
- Convert a manual script into a scheduled pipeline.
- Explain plugin options.
- Draft transformation SQL inside a workflow.
- Find likely syntax errors quickly.

## Bad AI use cases

- Trusting generated code without running it.
- Asking for a specific plugin version without docs.
- Letting AI invent task type names that do not exist.
- Adding secrets or credentials directly into YAML.

## Core rule

AI should accelerate iteration, not replace pipeline validation. You still need to run flows, inspect logs, and test outputs.

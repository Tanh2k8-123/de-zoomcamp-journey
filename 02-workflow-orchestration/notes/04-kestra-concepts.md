# Unit 2 Unit 4 - Kestra Concepts

- Flow: the complete declarative workflow.
- Task: an ordered step executed by the flow.
- Input: runtime values passed into a flow.
- Variable: reusable templated value inside a flow.
- Output: data emitted by a task and consumed by later tasks.
- Execution: one run of a flow, including its state and logs.
- Trigger: an automatic way to start exections, such as cron.
- Plugin defaults: shared defaults for all tasks of the same type.
- Concurrency: rules controlling parallel exections.
